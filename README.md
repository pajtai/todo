# Todo

A multi-user todo app focused on reviewing what you've completed and which of your categories each todo belongs to.

- **Stack:** Next.js 16 (App Router, TypeScript, Tailwind) + Supabase (Postgres, Auth)
- **Hosting:** Vercel
